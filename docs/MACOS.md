# macOS Public Beta

This is the Mac version of the Virtual Pharmacology Laboratory.

It is built for Intel Mac computers. Apple silicon Mac computers can also use it with Rosetta 2.

After downloading, unzip the file and open **Pharmacology CAL**. If macOS shows a security message, Control click the application, select **Open**, and confirm once.

This public beta is for pharmacology teaching and learning. Feedback and suggestions are welcome.
